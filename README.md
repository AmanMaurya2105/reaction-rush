Reaction Bloom

Reaction Bloom is a browser-based reaction-time game by The Medicine Maven.

Game

Players complete 3 automatic rounds:

1. Land
2. Underwater
3. Space

Each round lasts 15 seconds. Players tap the target as quickly as possible. The game records reaction times, calculates round averages, and produces a final average.

Current Version

This version includes:

• 3 × 15-second rounds
• Ready → Pumpkin → Go countdown
• Immediate next target after a successful tap
• 1.5-second target timeout if untouched
• Round averages
• Final average reaction time
• Fastest reaction time
• Animal comparison/ranking system
• Leaderboard
• Animal rankings
• Animal-specific reaction facts
• Animal-specific fun facts
• No animal image database
• Responsive mobile and desktop interface
• Land, underwater and space visual themes
• Ambient game audio
• Local browser leaderboard using localStorage

Animal Results

Animal images have intentionally been removed from this version because incorrect or mismatched animal images were appearing.

The result uses the animal name only, together with:

• Reaction fact
• Fun fact

Each animal has its own facts rather than using one repeated generic fact.

Running the Game

The project is a single HTML file.

Open:

index.html

in a modern browser.

No installation or build process is required.

GitHub Pages

1. Create a GitHub repository.
2. Upload:
  • index.html
  • README.md
3. Open the repository’s Settings.
4. Select Pages.
5. Choose:
  • Deploy from a branch
  • Branch: main
  • Folder: / (root)
6. Save.

GitHub Pages will publish the game.

Important

The leaderboard in this version is stored in the browser using localStorage.

Therefore it is not a global online leaderboard. Scores are tied to the browser/device unless a backend is added later.
